# SGTH — Sistema de Gestão de Triagem Hospitalar

Projeto acadêmico desenvolvido em **Java**, voltado à organização e ao gerenciamento de informações relacionadas ao atendimento e à triagem hospitalar.

O sistema registra informações dos pacientes, identifica a prioridade de atendimento e organiza a fila de acordo com a classificação atribuída.

---

## Tecnologias Utilizadas

- Java
- IntelliJ IDEA
- Arquitetura Controller, Service e Repository
- Persistência de dados em arquivos CSV
- Modelagem UML

---

## Funcionalidades

- Cadastro e gerenciamento de pacientes
- Registro de triagens hospitalares
- Gerenciamento de visitas
- Cadastro de usuários
- Organização e consulta de informações
- Armazenamento de dados em arquivos CSV

---

## Como Executar

Instale o Java JDK e o IntelliJ IDEA.

Clone o repositório ou baixe o projeto em ZIP.

Abra a pasta do projeto no IntelliJ IDEA.

Aguarde a configuração e o carregamento das dependências, se houver.

Localize a classe principal que contém o método main().

Execute a aplicação pela opção Run do IntelliJ IDEA.


**Observação:** Projeto desenvolvido para fins acadêmicos, durante a graduação em Análise e Desenvolvimento de Sistemas no Instituto Infnet.
